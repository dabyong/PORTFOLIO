03 / nyc-taxi-demand-forecasting COMPLETED ANALYSIS

POWER BI / FORECAST PERFORMANCE

PROJECT 03 · TIME-SERIES FORECASTING & OPERATIONS ANALYTICS

NYC Yellow Taxi Demand Forecasting & Operational Planning

An end-to-end study using 2024–2025 NYC Yellow Taxi trip records. I used DuckDB and Python to audit and aggregate recorded pickups by day and pickup zone, engineered lag and calendar features, compared forecasting baselines against Histogram Gradient Boosting, and built a three-page Power BI report for operational planning reviews.

10.20%ML zone-day WAPE*
16.73%Last-week baseline WAPE
39.04%Relative error reduction

Key finding: The selected model reduced zone-day weighted absolute percentage error by 39.04% relative to a same-weekday-last-week benchmark on an untouched October–December 2025 test period. Forecasts can help prioritize zone-level coverage reviews, but do not establish vehicle shortages.

PROJECT 04 · APPLIED MACHINE LEARNING & RESPONSIBLE ANALYTICS

AI-Powered Marketing Lead Prioritization

A reproducible bank-marketing research prototype using chronological evaluation, leakage-aware feature preparation, and Random Forest classification. I compared multiple models, assessed calibration and subgroup disparities, and deployed a Streamlit demo that ranks synthetic leads for a fixed manual-review capacity.

1.89×Top-10% holdout lift*
448 / 618Historical subscribers found
12 / 12Automated QA tests passed

Key finding: Ranking the top 10% of holdout contacts captured 448 historical subscribers versus about 238 expected from random selection at equal capacity. This is retrospective concentration, not causal campaign uplift.
